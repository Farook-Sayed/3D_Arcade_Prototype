A 3D arcade racing game prototype built with Godot and GDScript. Players navigate a track with ramps, bridges, and checkpoints, using acceleration, braking, steering, and handbrake drifting to complete three laps against the clock. The project features custom vehicle movement, surface based speed changes, a smooth following camera, checkpoint and lap tracking, a countdown timer and a race HUD.
